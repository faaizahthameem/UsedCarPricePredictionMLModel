# Used Car Price Prediction (Machine Learning Project)

Predicting the right price for a used car is essential for profitability, customer trust, and operational efficiency. This project builds a machine learning model using historical used‑car sales data from India to generate accurate, fair, and consistent price predictions. By analyzing key vehicle attributes—such as brand, model, mileage, and age—and addressing data quality issues like missing values and outliers, the model identifies what truly influences pricing and provides interpretable, data‑driven estimates. The goal is to help used‑car companies move away from subjective pricing, make faster and more reliable decisions, reduce inventory time, and ultimately increase profitability.

---

## Features

- Data cleaning and preprocessing  
- Exploratory data analysis (EDA)  
- Feature engineering  
- Multiple regression model experiments  
- Model evaluation using standard metrics  
- Insights into key pricing factors  
- Interpretable predictions for real‑world use  

---

## Objectives

- Predict used‑car prices accurately using machine learning  
- Replace inconsistent manual pricing with a data‑driven system  
- Identify the most influential features affecting price  
- Improve decision‑making speed and consistency  
- Support profitability through fair and competitive pricing  

---

## Key Questions Addressed

- Which attributes most strongly influence used‑car prices?  
- How reliable is the historical data?  
- What missing values or outliers need correction?  
- Which regression model performs best for this dataset?  
- How should model performance be measured?  
- What patterns emerge from analyzing distributions and correlations?
